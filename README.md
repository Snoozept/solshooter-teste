# LOUDOUT — test build (Android)

Install / update: [LOUDOUT test app (APK)](https://github.com/Snoozept/solshooter-teste/raw/main/SolShoot-teste.apk) — build 102

The test app tells you by itself when there is a new build. The game code is not here.

Windows / macOS: download the program once —
[Windows](https://github.com/Snoozept/solshooter-teste/releases/download/pc/SolShoot-Windows.zip) ·
[Mac Apple Silicon (M1–M4)](https://github.com/Snoozept/solshooter-teste/releases/download/pc/SolShoot-Mac-AppleSilicon.zip) ·
[Mac Intel](https://github.com/Snoozept/solshooter-teste/releases/download/pc/SolShoot-Mac-Intel.zip).
After that it updates itself from `SolShoot-web-102.zip` (same banner, one click).

iPhone / any browser: open https://snoozept.github.io/solshooter-teste/ in Safari, then Share → "Add to Home Screen".
It opens like an app, works without internet once loaded, and updates itself when online.

Online server (Windows): put [iniciar-servidor.bat](https://github.com/Snoozept/solshooter-teste/raw/main/iniciar-servidor.bat)
in its own folder and open it. It downloads what it needs, starts with Windows and shows the address to type in the game.
